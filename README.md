# 🤖 AI LinkedIn Content Agent

An AI-powered LinkedIn content generation and publishing system built using **AutoGen, OpenAI, SerpApi, Guardrails, DeepEval, Streamlit, and the LinkedIn API**.

The application uses multiple AI agents to research a topic, create professional LinkedIn content, validate the generated content, obtain human approval, and publish the approved post directly to LinkedIn.

---

## 🚀 Project Overview

The AI LinkedIn Content Agent automates the complete content creation workflow:

```text
User Topic
    ↓
Research Agent
    ↓
Content Writer Agent
    ↓
SEO / LinkedIn Agent
    ↓
Guardrails Validation
    ↓
DeepEval Evaluation
    ↓
Human Review & Approval
    ↓
LinkedIn OAuth
    ↓
Direct LinkedIn API Publishing
